Four source-bound interleaved canonical-real certificates

Extract certificates.tar.gz and run `python3 -m lark_kernels check rows-1 --timeout 600`, or select rows-3, rows-256 or rows-65535. The included wheel contains the complete owned proof closure. Initialize the pinned optional Mathlib dependencies, then set LARK_REAL_PROJECT to that initialized lean-real project. The separately frozen source archive and independent replay are in ../canonical-real-v1 and ../canonical-real-validation-v1.

The proof uses exact reals and identity storage conversions. Split-half correctness and original-paper completion are not claimed.
