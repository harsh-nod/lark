# Recorded bounded PTX results

**The original paper is not fully reproduced.** This independent CPU study adds
four tiny scalar PTX certificates to the same unmodified Lean machine used by
the bounded CUDA/HIP profile. There are no NVIDIA execution or timing results.

All four certificates verified and passed another source-bound recheck in
Lean 4.19.0. NVIDIA `ptxas` 12.9.86 accepted each exact fixture for `sm_80`.
The generated cubins are archived but were not executed.

| Independent PTX fixture | Workload | Lowered instructions | Memory accesses | Lean export / recheck | Assembly |
| --- | --- | ---: | ---: | --- | --- |
| Copy | 2 float32 values, full CTA barrier | 13 | 4 | verified / verified | accepted |
| Vector add | 3 float32 values, 4 launched threads | 25 | 9 | verified / verified | accepted |
| ReLU | 2 float32 values | 12 | 4 | verified / verified | accepted |
| GEMV | [2,2] @ [2,1] | 25 | 10 | verified / verified | accepted |

The instruction counts include runtime predicate assignments and generated byte
alignment guards. These are verifier instructions, not SASS instruction counts.
The theorems quantify over every input and outside-memory value under the
existing abstract scalar operations, not IEEE rounding behavior. The generated
axiom audit contains only standard Lean axioms (`propext`, `Quot.sound`).

Four independent mutations of the vector-add source were rejected directly by
Lean with Python preflight bypassed: changed arithmetic, conflicting output
addresses, misaligned byte strides, and a skipped predicate definition. There
were zero accepted mutants and zero timeouts. These controls test this reader's
binding and runtime obligations; they are not the original paper's 42 mutants
or its diagnostic-channel counts.

The [raw completed study](results/cpu-20261109/results.json) contains the exact
sources, immutable theorem statements, proposals, hashes, assembler records,
compiler outputs, negative-control Lean files and complete logs. The
[archive manifest](results/cpu-20261109/manifest.json) binds every recorded file.
`summarize.py` checks that manifest, pinned reader sources, original fixtures
and reconstructed positive/negative statements before producing
[summary.json](results/summary.json). It reads evidence; it does not claim a new
Lean run. The [source bundle and validation record](results/validation.json)
allow the exact implementation to be retained independently of later changes.

Validation passed eight PTX tests including real Lean integration and negative
controls, six final frontend controls, and all 22 existing baseline tests. A
newly built wheel rechecked the vector-add export from outside the checkout.
The [method and commands](README.md) describe the accepted subset and trust
boundary. Broader PTX, optimized Level-2/production kernels, general loops,
collectives and NVIDIA hardware evidence remain absent.
