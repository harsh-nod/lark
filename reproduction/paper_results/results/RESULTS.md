# Result-by-result paper audit

**The original paper is not fully reproduced.** This inventory follows the
arXiv v1 preprint's actual source inputs: **17 tables, seven outer figure
groups and 16 additional narrative anchors**. These overlap; they are not
forty comparable experiments or a denominator for a completion percentage.

The source archive and every evidence file below are bound by SHA-256 in
[audit.json](audit.json). Enumeration checks source coverage; the target
interpretations and dependency assessments are authored judgments. This audit
does not rerun Lean, models or GPUs, and file integrity alone does not prove
a study's validity. Follow the linked study records for checks and limits.

All seventeen workload shapes have independent full-size contracts (34
HIP/CUDA certificates), with 170 exact-source trials and 19,387,200 scalar
comparisons per MI350X host. The separate shuffle and single-instruction
MFMA studies and completed free local model cohorts are additional evidence.
None supplies the original optimized registry or historical model outcomes.

## Concrete dependencies

- **registry**: Authors' original task/language registry: exact kernel bytes, signatures, launches, reference modules, pinned operation tables, and exported proofs. Independent programs at equal shapes cannot replace these inputs.
- **harness**: Original proof-agent harness and prompts, segmentation/scaffolding, tool protocol, retries, stopping rules, context compaction, model settings and usage accounting.
- **runs**: Original request/response and checker traces, model revisions and original hosted-model outcomes. Offline/free inference does not recover historical paid or closed-model runs.
- **mutants**: All 42 original mutant source files, baseline bindings, rule assignments, final-run traces and rejection-channel decisions, including independent second opinions.
- **production**: The ten exact adapted production sources, upstream commits, ordered rewrites/departures, argument signatures and launch metadata; nine accepted full-kernel proof projects and the rejected kernel trace.
- **hardware**: Original optimized kernels and numerical contracts, complete fastest-vendor baselines, H100 execution for PTX/CUDA and same-device MI300X HIP measurements. MI350X measurements cannot fill H100 cells.
- **semantics**: Broader instruction/readers and scalable tiled/online/combined collective proofs. The present scalar, separate shuffle and single MFMA profiles do not cover the original optimized programs.
- **history**: Authors' source tree and development records. An independent implementation cannot recreate historical person-days, original source-line totals or original code-sharing percentages.
- **gqa_export**: Authors' supplementary standalone GQA proof project and its pinned toolchain/dependencies; it was not present in the inspected manuscript archive or bounded release endpoints.
- **specification**: Authors' elaborated Lean module formalizations, metaprogram/reference tests, accepted shape/precision contracts and associated trusted-assumption reports.

## Bounded artifact search

The expanded read-only GitHub audit inspected the author's eleven public
repositories and the related AICrossSim organization. At the recorded
revision, `jiaeenie/gpu_optim_bench` identifies itself as FlashInfer-Bench;
its complete 559-entry tree has no LARK/Lean/KernelCraft-named path or
`.lean`, `.ptx` or `.hip` file. This does not exclude hidden material in
other files, other branches, unsearched repositories or a later release.
The related `AICrossSim/KernelCraft` repository was empty at the check.
[Raw commands and responses](../../results/artifact-expanded-20261110.json).

The source inventory has 47 manuscript/figure files and no implementation
or original GQA project. No author contact was made. Artifact availability
is an external dependency; broader software support remains implementation
work, and no AMD result can be relabeled as an H100 measurement.
