# Result-by-result paper audit

**The original paper is not fully reproduced.** This inventory follows the
arXiv v1 preprint's actual source inputs: **17 tables, seven outer figure
groups and 16 additional narrative anchors**. These overlap; they are not
forty comparable experiments or a denominator for a completion percentage.

The source archive and every evidence file below are bound by SHA-256 in
[audit.json](audit.json). Enumeration checks source coverage; the target
interpretations and dependency assessments are authored judgments. This audit
does not rerun Lean, models or GPUs, and file integrity alone does not prove
a study's validity. Follow the linked study records for checks and limits.

All seventeen workload shapes have independent full-size contracts (34
HIP/CUDA certificates), with 170 exact-source trials and 19,387,200 scalar
comparisons per MI350X host. The separate shuffle and single-instruction
MFMA studies and completed free local model cohorts are additional evidence.
The later upstream-derived SiLU study supplies eight native multiwave
HIP/CUDA certificates for one independently adapted family. The exact-real
wave64 reduction study supplies one further primitive, with 17,408 source-tree
bit comparisons per host and cancellation disagreements reported separately.
The independent native weighted RMSNorm study adds four source-bound
canonical-real certificates and fresh rechecks at 1, 3, 64 and 255 rows.
Its whole-launch proof covers all inputs/outside memory for 1<=rows<256
at width16384, native block1024/wave64, including logical-16 shuffles.
Earlier both-host measurements add 127,008,768 CPU-reference comparisons
with zero tolerance failures; signed-zero and one-half-ULP differences
remain explicit. No IEEE error theorem or complete upstream API is claimed.
The independent native online-attention study adds full actual-launch
execution, actual-trace race freedom and dense-real correctness for all
groups 1..65535 at N128/D256, block32/wave64. It proves every output after
all four key tiles, nine block phases and final PC90 halt, preserving the
source's arithmetic order and half-cast sites in its abstract-operator theorem.
Four canonical-real exports and two fresh standalone archive replays pass.
The real interpretation makes casts identities; IEEE equivalence and a
floating-point error bound remain unproved. Earlier paired AMD measurements
supply 3,145,728 CPU-double comparisons with zero tolerance failures; measured
FP16-versus-rounded-FP32 differences remain explicit. This ledger adds no
GPU trials, model calls or Lean checks of its own.
None supplies the original optimized registry or historical model outcomes.

This snapshot freezes selected evidence from experiment-code commit `3401f08`
and the recorded release/CI responses. Its replay reads that frozen bundle,
so later repository documentation changes do not invalidate this audit.
Evidence links for existing studies point to that exact Git commit.

## Concrete dependencies

- **registry** (original artifacts): Authors' original task/language registry: exact kernel bytes, signatures, launches, reference modules, pinned operation tables, and exported proofs. Independent programs at equal shapes cannot replace these inputs.
- **harness** (original artifacts / software reconstruction): Original proof-agent harness and prompts, segmentation/scaffolding, tool protocol, retries, stopping rules, context compaction, model settings and usage accounting.
- **runs** (original traces; closed-model regeneration conflicts with offline/free calls): Original request/response and checker traces, model revisions and original hosted-model outcomes. Offline/free inference does not recover historical paid or closed-model runs.
- **mutants** (original artifacts): All 42 original mutant source files, baseline bindings, rule assignments, final-run traces and rejection-channel decisions, including independent second opinions.
- **production** (original artifacts and proof engineering): The ten exact adapted production sources, upstream commits, ordered rewrites/departures, argument signatures and launch metadata; nine accepted full-kernel proof projects and the rejected kernel trace.
- **hardware** (original artifacts and unavailable NVIDIA hardware; original MI300X protocol also required): Original optimized kernels and numerical contracts, complete fastest-vendor baselines, H100 execution for PTX/CUDA and same-device MI300X HIP measurements. MI350X measurements cannot fill H100 cells.
- **semantics** (remaining software work): Broader readers and scalable packed/vector, combined multi-warp collective and arbitrary sparse-subgroup proofs remain software work. Complete independent native multiwave activation, weighted RMSNorm and fixed-shape online-attention launches, aligned logical-16 cohorts inside physical wave64, single-shape MFMA and exact-real wave-sum profiles do not cover the original optimized registry. The native attention source uses a separately scoped development reader and source-bound export checker; its proof does not broaden the ordinary reader automatically.
- **history** (original historical records): Authors' source tree and development records. An independent implementation cannot recreate historical person-days, original source-line totals or original code-sharing percentages.
- **gqa_export** (original artifact): Authors' supplementary standalone GQA proof project and its pinned toolchain/dependencies; it was not present in the inspected manuscript archive or bounded release endpoints.
- **specification** (original artifacts and trusted-reference validation): Authors' elaborated Lean module formalizations, metaprogram/reference tests, accepted shape/precision contracts and associated trusted-assumption reports.
